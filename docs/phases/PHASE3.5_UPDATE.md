# Phase 3.5 更新 - 军队移动与战斗系统

## 🎮 新增功能

### 1. 军队移动系统 ✅
- **点击选择军队**: 在地图上点击己方军队即可选中（显示金色高亮圆圈）
- **点击移动**: 选中军队后，点击地图任意位置即可移动
- **实时移动**: 军队以 2.0 单位/秒的速度移动
- **路径显示**: 移动中的军队显示黄色虚线路径
- **到达提示**: 军队到达目的地后自动停止

### 2. 攻城战系统 ✅
- **自动触发**: 军队到达敌对城池时自动开始攻城
- **战力计算**: 
  - 攻方 = 兵力×10 + 武将加成 + 士气加成
  - 守方 = 守军×8 + 城墙加成 + 太守加成
- **胜负判定**: 攻击力 ≥ 防御力×1.5 时攻城成功
- **伤亡计算**: 
  - 成功损失30%兵力
  - 失败损失50%兵力
- **城池占领**: 攻城成功后自动占领，更新势力城池列表

### 3. 野战系统 ✅
- **自动触发**: 两支敌对军队相遇时（距离<0.5）自动战斗
- **战斗模拟**: 使用 simulateBattle 函数计算
- **伤亡分配**: 基于双方战力对比
- **胜负判定**: 失败方军队被消灭

### 4. UI增强 ✅
- **军队详情面板**: 点击军队后显示详细信息
  - 统帅、势力、兵力、士气
  - 当前位置、目标位置
  - 操作提示和解散按钮
- **战斗通知**: 
  - 攻城成功/失败提示
  - 野战结束提示
  - 城池占领提示
- **控制台日志**: 详细记录战斗过程

## 🎯 使用指南

### 如何移动军队
1. 点击底部"军事"按钮，招募军队
2. 在地图上点击你的军队（三角形图标）
3. 军队被选中后显示金色圆圈
4. 点击地图上你想去的位置
5. 军队开始移动，显示黄色路径虚线
6. 等待军队到达目的地

### 如何进行攻城
1. 招募足够强大的军队（建议500+士兵）
2. 移动军队到敌对城池位置
3. 军队到达后自动触发攻城战
4. 查看战斗通知了解结果
5. 攻城成功后城池归你所有

### 如何查看军队信息
1. 在地图上点击军队图标
2. 右侧面板显示军队详情
3. 可以看到兵力、士气、位置等信息
4. 点击"解散军队"按钮可以解散
