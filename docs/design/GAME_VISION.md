# GAME VISION

## 目标一句话
做一款以宫廷政治为主轴、以朝会决策驱动国家命运的三国策略游戏。

## 玩家体验目标
- 玩家扮演君主，不做战场微操。
- 核心乐趣是"听政-拍板-承担后果"。
- 在不完全信息下进行国家级决策。
- 保持较强历史沉浸感，关键史实不随意改写。

## 主循环定位
- 采用朝会主导的分段推进，而非全自由实时操控。
- 以旬为基础推进粒度。
- 每月初一大朝会是主要决策窗口。
- 紧急朝会仅在重大军事或灾害事件时触发。

## MVP 成功画面
- 玩家可连续体验至少 12 个月闭环。
- 每月形成"朝会决策 -> 执行反馈 -> 下月再决策"的稳定节奏。
- 宫廷政治感与历史沉浸感可被明确感知。

## 历史真实性原则
- 史实冲突优先参考《三国志》。
- 锁定项：官制、地名、年代、人物生卒、重大事件。
- 对玩法友好的抽象允许存在，但不得破坏锁定项。

## 未来扩展方向（非 MVP）
- 官员提案从规则模板扩展到 LLM 生成。
- 在保留校验机制的前提下提高叙事变化度。
