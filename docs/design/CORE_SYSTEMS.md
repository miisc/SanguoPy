# CORE SYSTEMS

## 1. 时间与流程规则
- 时间粒度：旬推进。
- 每月结构：
  - 月初一：大朝会（主要决策）。
  - 其余时间：执行阶段（结果展开）。
- 紧急朝会触发条件：仅重大军事事件或重大灾害事件。
- 冲突裁决：MVP 阶段本文件为实现基线，若与 requirements.md 冲突，以本文件为准。

## 2. 玩家权限边界
- 朝会内：可进行国家级核心决策。
- 朝会外：仅允许发布军事与情报类临时指令。
- 朝会外临时指令必须消耗诏令权威。

## 3. 诏令权威系统
- 资源名：诏令权威。
- 上限：100。
- 初始值：50。
- 恢复规则：每月初一一次性恢复 5%（不可超过上限）。
- 恢复公式：
  - 恢复值 = ROUND(当前权威 x 0.05)
  - 新权威 = MIN(100, 当前权威 + 恢复值)
  - ROUND 采用四舍五入。
- 扣减顺序：
  - 先校验白名单与触发条件。
  - 再校验权威是否足够。
  - 校验通过后才执行扣减与指令落地。
- 下限规则：权威不得小于 0，余额不足时指令直接拒绝。
- 用途：支付朝会外临时指令成本。

## 4. 临时指令白名单（固定类别）
- 边关急袭应对令（军事）
- 粮道中断处置令（军事）
- 重大灾害赈济令（情报/军政联动）
- 叛乱与哗变平定令（军事）
- 敌都与战略通道情报急令（情报）
- 外敌联合征兆警戒令（情报）

统一参数（MVP）：
- 指令成本：每次固定消耗 10 点诏令权威。
- 指令冷却：同类指令最短间隔 1 旬。
- 使用上限：每旬可执行次数由当前诏令权威容量动态决定。
  - 计算公式：每旬上限 = FLOOR(当前诏令权威 / 10)
  - 安全约束：当可用权威不足 10 时，上限为 0；任何执行后权威不得小于 0。

说明：白名单外指令在朝会外不可发布。

## 5. 紧急朝会触发阈值（量化）
- 触发总原则：仅军事或灾害类重大事件触发。
- 触发行为：满足触发条件后，立即中断当前执行阶段并进入紧急朝会。
- 重大军事事件判定（满足任一即触发）：
  - 边境城市遭受攻击预警或围城。
  - 粮道中断导致主力军粮预计不足 1 旬。
  - 战略通道（关隘/渡口）状态由可通行变为失守。
- 重大灾害事件判定（满足任一即触发）：
  - 单旬内同一州郡出现大旱、洪涝或疫病中的任一重大等级事件。
  - 都城所在区域发生灾害且影响到秩序或补给。

## 6. 迷雾与情报可见性
- 情报迷雾遵循史实优先。
- 概略信息最小展示集合：仅城市名。
- 不显示：城市归属、兵力等具体军情。

史实裁决优先级：
- 一级来源：三国志。
- 发生冲突时，以一级来源为准并回退到对应史实版本。

## 7. 提案生成与校验
- 五维基础数值范围：military、economy、technology、public_order、diplomacy 统一为 0 到 100。
- 边界处理规则：任何结算后数值低于 0 则置为 0，高于 100 则置为 100。
- MVP 阶段：官员提案由规则模板生成。
- 模板字段：固定结构，不允许自由缺省。
- 后续扩展：可接入 LLM 生成内容。
- LLM 约束：允许改变提案效果数值，但必须通过校验网关。

固定字段（MVP）：
- proposal_id
- proposal_type
- title
- background
- options
- base_effects
- constraints
- source_tag

建议的最小校验网关：
- 结构校验：字段完整性与类型合法性。
- 幅度校验：单项数值变化绝对值不超过 15。
- 平衡校验：收益与代价满足基础平衡约束。
- 史实校验：不得违反锁定史实项。
- 回退机制：校验失败时回退模板默认值。
- 审计记录：保存模板原值、LLM 变更值、校验结果与回退原因。

## 8. 重大事件库（MVP）
- 数量：10 个（通用模板优先）。
- 冷却作用域：按事件类型冷却（event_type），同类型事件共享冷却窗口。
- 统一字段结构：
  - event_id
  - event_type
  - trigger_conditions
  - priority
  - options
  - effects
  - cooldown_xun
  - emergency_meeting_required
- 事件模板：
  - 边关急报（敌军压境）
  - 粮道断绝
  - 大旱灾
  - 洪涝灾
  - 疫病蔓延
  - 郡县叛乱
  - 军中哗变
  - 敌都异动
  - 战略通道开启/失守
  - 都城危机

## 9. MVP 闭环验收标准
- 连续运行 12 个月不破坏。
- 朝会外指令严格受白名单与诏令权威约束。
- 紧急朝会仅由规定事件触发。
- 迷雾下不泄露城市归属与兵力信息。
- 模板提案可稳定执行，LLM 改动可被校验与回退。
