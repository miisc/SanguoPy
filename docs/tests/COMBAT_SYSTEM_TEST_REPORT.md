- **测试人员**: GitHub Copilot
- **测试环境**: Chrome/Edge浏览器，Python HTTP Server (端口8000)

---

## 功能概述

本次更新添加了完整的军队移动和战斗系统，包括：
1. **军队点击选择机制** - 可以在地图上点击选择军队
2. **军队移动** - 选中军队后点击目标位置移动
3. **攻城战** - 军队到达敌对城池时自动触发攻城
4. **野战** - 两支敌对军队相遇时自动触发战斗
5. **战斗结果反馈** - 伤亡计算、城池占领、军队消灭等
