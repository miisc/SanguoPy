# 道路系统 - 功能说明

## ✅ 已添加功能

### 1. 道路数据结构
- **位置**: `js/data/structures.js`
- **函数**: `createRoad(id, fromCityId, toCityId, level)`
- **属性**:
  - `id`: 道路唯一标识
  - `from`: 起始城池ID
  - `to`: 目标城池ID
  - `level`: 道路等级（1-3）
  - `condition`: 道路状况（0-100）
  - `buildProgress`: 建造进度
  - `underConstruction`: 是否正在建造

### 2. 道路等级系统

#### 等级1 - 小路
- **宽度**: 2像素
- **颜色**: 褐色 (#8b7355)
- **样式**: 虚线
- **速度加成**: 无

#### 等级2 - 驿道
- **宽度**: 3像素
- **颜色**: 土黄色 (#b8956a)
- **样式**: 实线
- **速度加成**: 建议 1.2倍

#### 等级3 - 官道
- **宽度**: 4像素
- **颜色**: 金色 (#d4af37)
- **样式**: 实线
- **速度加成**: 建议 1.5倍

### 3. 初始道路网络

游戏默认包含8条道路：

1. **成都 → 汉中** (等级2，驿道)
   - 蜀国通道

2. **汉中 → 襄阳** (等级2，驿道)
   - 中部通道

3. **洛阳 → 许昌** (等级3，官道)
   - 魏国官道，最高等级

4. **许昌 → 襄阳** (等级2，驿道)
   - 南下通道

5. **襄阳 → 江陵** (等级2，驿道)
   - 荆州通道

6. **江陵 → 长沙** (等级2，驿道)
   - 南方通道

7. **长沙 → 建业** (等级2，驿道)
   - 吴国通道

8. **江陵 → 建业** (等级2，驿道)
   - 东部通道

## 🎨 视觉效果

### 渲染特性
- **透明度**: 60%（不遮挡其他元素）
- **绘制顺序**: 网格 → 道路 → 城池 → 军队
- **缩放支持**: 道路宽度随地图缩放变化
- **层级**: 道路作为底层，不会遮挡城池和军队

### 颜色方案
- **小路**: 褐色虚线，低调不显眼
- **驿道**: 土黄色实线，清晰可见
- **官道**: 金色实线，醒目突出

---

## 🚀 使用方式

### 查看道路
1. 启动游戏
2. 在地图上可以看到连接城池的线条
3. 金色线 = 官道（洛阳↔许昌）
4. 土黄色线 = 驿道（其他主要道路）
5. 虚线 = 小路（未使用）

### 道路对游戏的影响（当前）
- ✅ **视觉引导**: 帮助玩家了解城池之间的连接关系
- ✅ **战略指示**: 显示主要的进攻/防守路线
- ⚠️ **移动速度**: 暂未实现速度加成（可后续添加）

## 📈 未来扩展

### 短期计划（待实现）
1. **移动速度加成**
   - 军队在道路上移动更快
   - 等级2道路: 1.2倍速
   - 等级3道路: 1.5倍速

2. **道路升级系统**
   - 玩家可以升级控制区域内的道路

3. **道路状况系统**

   - 定期维护需要消耗资源
   - 状况影响移动速度

### 中期计划
1. **动态道路建造**
   - 玩家可以在任意两城市间建造新道路

2. **道路控制权**
   - 道路显示控制势力颜色

3. **商路系统**
   - 道路带来贸易收入
   - 官道收入最高

### 长期计划
