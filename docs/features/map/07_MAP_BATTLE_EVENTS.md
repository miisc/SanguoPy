# 实时更新系统

## 功能说明

实现实时游戏时间流逝和状态更新，支持暂停、加速等功能。

## 核心特性

### 1. 时间控制系统
- ✅ **实时流逝**: 游戏时间持续流逝（可暂停）
- ✅ **速度控制**: 支持正常、2倍速、4倍速、暂停
- ✅ **时间显示**: 实时显示当前年份、季节、日期
- ✅ **季节影响**: 不同季节对游戏产生不同影响

### 2. 更新机制
- ✅ **定时器驱动**: 使用PyQt QTimer实现游戏循环
- ✅ **增量更新**: 每帧只更新必要的游戏状态
- ✅ **事件触发**: 基于时间触发各种游戏事件

## 技术实现

### 时间控制系统设计
游戏时间控制系统需要包含以下核心组件：
- 时间管理器：管理游戏时间的流逝和状态
- 定时器控制：控制游戏循环和更新频率
- 速度控制：支持不同速度的游戏时间流逝
- 暂停机制：支持游戏的暂停和恢复

### 时间数据结构
时间系统需要以下数据结构：
- 当前时间：包含年份、季节、日期等信息
- 速度设置：当前游戏速度倍数
- 暂停状态：游戏是否处于暂停状态
- 定时器配置：定时器的间隔和配置

### UI集成设计
时间控制UI需要包含以下元素：
- 时间显示：显示当前年份和季节
- 速度选择：提供不同速度选项
- 暂停按钮：控制游戏的暂停和恢复
- 状态指示：显示当前游戏状态

## 使用指南

### 玩家操作

1. **时间控制**
   - 使用顶部工具栏的速度下拉框选择游戏速度
   - 点击暂停/继续按钮控制游戏暂停

2. **观察变化**
   - 顶部时间标签显示当前年份和季节
   - 地图上的军队会根据时间自动移动
   - 资源产量会随时间自动更新

### 开发者集成

1. **监听时间事件**
   ```python
   # 监听时间更新
   game_controller.game_timer.time_updated.connect(on_time_update)
   
   # 监听季节变化
   game_controller.game_timer.season_changed.connect(on_season_change)
   ```

2. **自定义更新逻辑**
   ```python
   def custom_update_logic(day: int):
       # 自定义每天空逻辑
       if day % 30 == 0:  # 每月触发
           trigger_monthly_event()
   
   game_controller.game_timer.time_updated.connect(custom_update_logic)
   ```

## 性能考虑

### 定时器优化
- **可变间隔**: 根据游戏速度调整定时器间隔
- **批量更新**: 减少不必要的UI刷新
- **后台处理**: 耗时计算放入单独线程

### 内存管理
- **对象复用**: 重用定时器和事件对象
- **及时清理**: 移除不用的信号连接
