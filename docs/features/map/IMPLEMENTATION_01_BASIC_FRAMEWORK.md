# 基础地图框架与伪3D渲染 - 实现说明

## 概述

本文档描述了三国策略游戏基础地图框架与伪3D渲染功能的实现。这是地图系统的第一个核心feature，为后续所有地图功能奠定了基础。

## 实现内容

### 1. 核心类结构

#### 地形类型 (TerrainType)
- 定义了六种基础地形类型：平原、山地、丘陵、河流、森林、沙漠
- 每种地形类型具有中文名称、移动成本和防御加成属性
- 使用枚举实现，便于类型安全和扩展

#### 等距投影转换 (IsometricProjection)
- 实现网格坐标与屏幕坐标之间的转换
- 支持45度角的伪3D斜视视角
- 提供多种辅助方法：边界计算、中心点计算、点击检测等

#### 地图网格 (MapGrid)
- 存储和管理地图的网格数据和地形信息
- 提供地形获取、设置、区域操作等方法
- 支持随机位置获取和地形统计

#### 地形渲染器 (TerrainRenderer)
- 负责加载地形资源并渲染地形到场景中
- 如果找不到图像资源，会自动生成简单的占位图像
- 支持地形块的单独渲染和更新
- 实现正确的Z值排序，确保正确的渲染顺序

#### 地图视图 (MapView)
- 提供地图的显示和交互功能
- 支持鼠标滚轮缩放（0.5x到3.0x）
- 支持鼠标中键拖动浏览
- 提供地形块点击和悬停信号
- 自动调整视图大小以适应地图

创建了 `test_map_system.py` 作为测试应用程序，展示地图系统的基本功能：
- 显示50x50的网格地图

## 技术要点

### 1. 等距投影原理

等距投影通过以下公式实现网格坐标到屏幕坐标的转换：
```python
screen_x = (grid_x - grid_y) * (tile_width // 2)
screen_y = (grid_x + grid_y) * (tile_height // 2)
```

### 2. 渲染顺序

为了确保正确的遮挡关系，地形块按照以下顺序渲染：
- Y坐标越大的地形块越靠前
- X坐标的影响较小，用于微调
- 通过设置Z值实现：`item.setZValue(grid_y + grid_x * 0.01)`

### 3. 交互处理

- **缩放**：通过重写`wheelEvent`处理鼠标滚轮事件
- **拖动**：通过重写`mousePressEvent`、`mouseReleaseEvent`和`mouseMoveEvent`处理鼠标中键拖动
- **点击检测**：通过坐标转换和边界检测实现地形块点击检测

## 使用方法

1. 安装依赖：`pip install PyQt5`
2. 运行测试：`python test_map_system.py`
3. 交互操作：
   - 鼠标滚轮：缩放地图
   - 鼠标中键拖动：移动地图视图
   - 鼠标左键点击：选择地形块
   - 鼠标悬停：显示地形块信息
