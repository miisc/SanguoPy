# 势力控制区域与道路系统

本文档描述三国策略游戏中的势力控制区域和道路系统的设计与实现。

## 势力控制区域

### 视觉表现
- 使用半透明颜色覆盖显示各势力控制区域
- 不同势力使用不同颜色区分
- 边界区域使用渐变效果表示争议地区

### 区域计算
- 基于城市影响力范围计算控制区域
- 考虑地形因素对控制范围的影响
- 实时更新控制区域变化

## 道路系统

### 道路类型
- 主干道：连接主要城市，移动速度快
- 支路：连接次要地点，移动速度中等
- 小径：偏远地区连接，移动速度慢

### 道路显示
- 不同等级道路使用不同宽度和样式
- 道路随地形起伏显示
- 季节变化对道路通行的影响

### 移动计算
- 道路类型影响军队移动速度
- 地形复杂度影响移动成本
- 敌对区域移动速度降低

## 交互功能
- 点击控制区域显示势力详细信息
- 点击道路显示连接信息和移动时间
- 悬停显示相关城市和军队信息
