# Features 目录

本目录包含游戏地图系统的详细说明文档。

## 地图系统功能

地图系统是三国策略游戏的核心视觉和交互系统，采用伪3D斜视视角显示三国时期的中国地图。

### 地图功能模块（按开发顺序）

1. [00_MAP_SYSTEM_OVERVIEW.md](00_MAP_SYSTEM_OVERVIEW.md) - 地图系统总览
2. [01_MAP_BASIC_FRAMEWORK.md](01_MAP_BASIC_FRAMEWORK.md) - 基础地图框架与伪3D渲染
3. [02_MAP_TERRAIN_HEIGHT.md](02_MAP_TERRAIN_HEIGHT.md) - 地形高度与立体效果
4. [03_MAP_CITIES_FORTRESSES.md](03_MAP_CITIES_FORTRESSES.md) - 城池与关隘系统
5. [04_MAP_FACTION_TERRITORIES.md](04_MAP_FACTION_TERRITORIES.md) - 势力控制区域与道路系统
6. [05_MAP_INTERACTION.md](05_MAP_INTERACTION.md) - 地图交互功能完善
7. [06_MAP_ARMY_UNITS.md](06_MAP_ARMY_UNITS.md) - 军队单位与移动系统
8. [07_MAP_BATTLE_EVENTS.md](07_MAP_BATTLE_EVENTS.md) - 实时战斗与事件显示
