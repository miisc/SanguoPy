# 朝会系统功能文档

## 系统概述

朝会系统是三国策略游戏中的核心决策系统，模拟古代朝廷议事过程，让朝臣提出政见和方案，君主（玩家）从多个方案中选择执行，不同选择会对国家产生不同影响。
