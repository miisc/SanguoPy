# 基础朝会框架与UI

本文档描述三国策略游戏朝会系统的基础框架和用户界面设计。

## 基础框架

### 朝会触发机制
- **定期触发**：每月初或每季度初自动触发朝会
- **特殊触发**：重大事件发生时触发特殊朝会
- **手动触发**：君主可主动召开紧急朝会（消耗资源）

### 朝会流程
1. **朝会准备**：确定参与朝臣、生成议题
2. **朝会开始**：显示朝会场景和参与者
3. **议题陈述**：展示当前议题和背景信息
4. **朝臣发言**：朝臣按顺序表达意见和建议
5. **决策阶段**：君主从多个方案中选择执行
6. **朝会结束**：记录决策结果，更新游戏状态

### 数据模型
朝会系统需要定义以下核心数据结构：
- 朝会数据：包含朝会ID、日期、类型、参与者、议题、决策和状态
- 朝臣数据：包含朝臣ID、姓名、官职、属性、立场、忠诚度和关系
- 议题数据：包含议题ID、类型、标题、描述、背景、选项和条件
- 决策数据：包含关联议题ID、选择方案、结果和日期

## 用户界面设计

### 主界面布局
- **顶部区域**：显示朝会标题、日期、类型
- **中央区域**：朝会场景，显示参与朝臣位置
- **左侧区域**：当前议题信息和背景
- **右侧区域**：朝臣意见列表
- **底部区域**：决策选项和确认按钮

### 朝会场景设计
- **场景风格**：采用中国古代宫殿风格
- **朝臣位置**：按官职等级排列，高级官职靠近君主
- **视觉效果**：朝臣发言时有动画效果，选中时有高亮显示
- **氛围营造**：背景音乐和音效增强朝会氛围

### 议题展示界面
- **标题区域**：显示议题标题和类型
- **描述区域**：详细描述议题内容和背景
- **信息面板**：显示相关数据（资源、军队、外交关系等）
- **历史记录**：显示相关历史决策和事件

### 朝臣意见界面
- **朝臣列表**：显示所有参与朝臣及其官职
- **意见内容**：显示朝臣对当前议题的意见
- **立场指示**：用图标或颜色表示朝臣立场
- **关系影响**：显示朝臣间关系对意见的影响

### 决策选择界面
- **方案列表**：显示所有可选方案
- **方案详情**：点击查看方案的详细描述和预期结果
- **资源消耗**：显示执行方案所需的资源
- **风险评估**：显示方案的风险和不确定性
- **支持度**：显示各朝臣对不同方案的支持度

## 交互设计

### 基础交互
- **鼠标操作**：点击选择朝臣、方案，拖拽查看详情
- **键盘操作**：方向键导航，Enter确认，Esc取消
- **快捷键**：常用功能提供快捷键支持

### 信息展示
- **悬停提示**：鼠标悬停显示详细信息
- **详情面板**：点击查看完整信息
- **数据可视化**：使用图表展示复杂数据
- **动画效果**：平滑的过渡动画增强体验

### 反馈机制
- **选择反馈**：选中项有明显的视觉反馈
- **操作确认**：重要操作需要确认
- **结果预览**：决策前可预览可能结果
- **历史对比**：可查看类似历史决策的结果

## 技术实现

### 前端技术
- **UI框架**：使用PyQt的QWidget和QGraphicsScene
- **布局管理**：使用QVBoxLayout、QHBoxLayout等布局器
- **自定义控件**：创建朝臣头像、议题卡片等自定义控件
- **动画效果**：使用QPropertyAnimation实现动画

### 后端技术
- **数据管理**：使用SQLite或JSON存储朝会数据
- **事件系统**：使用信号槽机制处理交互事件
- **状态管理**：使用状态机管理朝会流程
- **逻辑处理**：使用策略模式处理不同类型议题

### 性能优化
- **延迟加载**：非关键信息延迟加载
- **缓存机制**：缓存常用数据减少计算
- **异步处理**：耗时操作使用异步处理
- **资源管理**：及时释放不用的资源
