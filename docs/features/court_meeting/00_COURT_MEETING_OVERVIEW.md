# 朝会系统总览

本文档提供三国策略游戏朝会系统的整体概述。

## 系统定位

朝会系统是游戏中的核心决策系统，模拟古代朝廷议事过程，让朝臣提出政见和方案，君主（玩家）从多个方案中选择执行，不同选择会对国家产生不同影响。系统严格遵循东汉时期'君主只能控制身边之人，以此治理天下'的历史真实机制。**整个游戏的主界面采用未央宫全景地图设计，玩家通过此地图导航所有游戏活动。**

## 核心功能

1. **皇宫全貌导航系统**：**作为游戏主界面**，通过点击不同宫殿处理不同类型政务，体现前朝后宫严格分离
2. **定期朝会机制**：每月自动触发朝会
3. **朝臣参与系统**：玩家手下的武将可作为朝臣参与议事
4. **议题生成系统**：根据当前局势自动生成朝会议题
5. **意见提出机制**：朝臣根据自己的属性和立场提出不同意见
6. **决策与结果系统**：不同选择会对国家产生不同影响，效果根据朝臣能力与忠诚度决定

## 技术架构

### 数据结构
- 朝会数据模型：时间、参与者、议题、决策等
- 朝臣数据模型：属性、立场、关系、忠诚度等
- 议题数据模型：类型、条件、选项、结果等
- 决策数据模型：选择、影响、历史记录等
- 宫殿数据模型：状态、关联事务、人员配置等

### 核心组件
- 皇宫全景视图：展示未央宫布局及宫殿状态
- 小黄门报告系统：事件驱动的事务通知机制
- 朝会控制器：管理朝会流程和状态
- 议题生成器：根据游戏状态生成合适议题
- 意见处理器：处理朝臣意见和立场
- 决策评估器：评估不同决策的影响
- 历史记录器：记录朝会历史和评价

### UI组件
- **皇宫全景视图**：**作为游戏主界面**，显示未央宫布局，可点击进入不同宫殿
- 宫殿状态指示：通过人员活动状态反映宫殿当前情况
- 小黄门报告动画：事件驱动的事务通知机制
- 朝会主界面：显示朝会场景和参与者
- 议题展示面板：显示当前议题和背景
- 意见列表：显示各朝臣的意见和建议
- 决策选择面板：显示可选方案和预期结果
- 历史记录面板：显示历史朝会和决策

## 开发计划

朝会系统将按照以下顺序逐步开发：

1. **皇宫主界面框架**：实现作为游戏主界面的皇宫全貌图及宫殿点击交互
2. 小黄门报告系统：实现事件驱动的事务通知机制
3. 朝会议题生成系统：实现议题生成逻辑和条件判断
4. 朝臣意见系统：实现朝臣意见生成和立场表达
5. 决策与结果系统：实现决策选择和结果影响
6. 朝会记录与历史评价：实现历史记录和评价系统
7. AI朝会系统：实现AI势力的朝会逻辑
8. 朝会系统集成与优化：与其他系统集成和性能优化

## 与其他系统的关系

- **武将系统**：朝臣来自武将系统，使用武将属性和能力
- **内政系统**：朝会决策影响内政发展和城池管理
- **军事系统**：军事议题影响军事行动和战争结果
- **外交系统**：外交议题影响与其他势力的关系
- **经济系统**：经济议题影响资源分配和商业活动
- **事件系统**：重大事件可能触发特殊朝会

## 设计原则

1. **历史真实性**：符合东汉末年的朝会制度和议事流程
2. **策略深度**：提供有意义的决策选择，影响游戏走向
3. **角色个性化**：不同朝臣有独特的性格和立场
4. **反馈明确**：决策结果清晰可见，便于玩家理解
5. **平衡性**：确保不同选项都有其价值和适用场景

## 数据模型

- 朝会数据模型：包含朝会ID、时间、参与者、议题和决策
- 朝臣数据模型：包含朝臣ID、姓名、官职、属性、立场、忠诚度和关系
- 议题数据模型：包含议题ID、类型、条件、选项和结果
- 决策数据模型：包含决策ID、选择、影响和历史记录
- 宫殿数据模型：包含宫殿ID、名称、状态、关联事务和人员配置
