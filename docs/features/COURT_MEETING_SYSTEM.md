# 朝会系统

## 概述

朝会系统是三国志策略游戏中的核心功能之一，模拟了三国时期的朝廷会议制度。玩家作为一方诸侯，需要定期处理来自大臣的建言、突发事件、政策建议等各类朝政事务。

## 功能特性

### 1. 事件触发机制

- **手动触发**：点击底部控制栏的"朝会"按钮即可召开朝会
- **自动触发**：每30天（约一个月游戏时间）自动生成新的朝会事件
- **事件队列**：支持多个事件排队等待处理

### 2. 事件类型

朝会系统包含8种不同类型的事件：

#### 2.1 经济报告 (ECONOMIC_REPORT)
- **必定出现**：每次朝会都会显示
- **内容**：国库状况、资源日产量、城池数量
- **决策**：仅供查看，无需做出决策

#### 2.2 大臣建言 (MINISTER_ADVICE)
- **触发概率**：随机
- **类型**：
  - **减税惠民**：消耗500金钱，提升民心
  - **加强军备**：消耗800金钱+200木材，所有城池驻军+100
  - **发展农业**：消耗600金钱，粮食+1000

#### 2.3 政策建议 (POLICY_PROPOSAL)
- **触发概率**：随机
- **类型**：
  - **轻徭薄赋政策**：金钱日产-20%，提升民心
  - **屯田政策**：粮食日产+30%

#### 2.4 人事推荐 (PERSONNEL_RECOMMENDATION)
- **触发条件**：有城池没有太守且有空闲武将
- **功能**：推荐合适的武将担任空缺城池的太守
- **决策**：可以选择任命或者暂不任命

#### 2.5 灾害报告 (DISASTER_REPORT)
- **触发概率**：20%
- **类型**：
  - **洪涝**：粮食产量-30%，粮食-500
  - **旱灾**：粮食产量-40%，人口-5%
  - **蝗灾**：粮食-800
- **决策**：
  - 拨款赈灾（1000金）：减轻灾害影响
  - 听天由命：承受全部损失

#### 2.6 宝物献上 (TREASURE_GIFT)
- **触发概率**：10%
- **宝物类型**：
  - 七星宝刀：金钱+1000
  - 玉玺：金钱+2000
  - 古籍兵书：木材+500
  - 名马：粮食+500

#### 2.7 战报捷报 (VICTORY_REPORT)
- **触发条件**：未来扩展功能
- **内容**：战斗胜利的报告

#### 2.8 外交消息 (DIPLOMATIC_MESSAGE)
- **触发条件**：未来扩展功能
- **内容**：来自其他势力的外交信息

### 3. 事件优先级

事件按照优先级排序显示：

- **紧急 (URGENT)**: ★★★ 红色 - 灾害等需要立即处理的事件
- **重要 (HIGH)**: ★★ 橙色 - 政策建议、人事任命等
- **一般 (NORMAL)**: ★ 蓝色 - 大臣建言、经济报告等
- **普通 (LOW)**: 灰色 - 宝物献上等

### 4. UI设计

#### 4.1 朝会按钮
- **位置**：底部控制栏，军事和内政按钮之间
- **样式**：金色渐变背景，特殊的发光效果
- **功能**：点击即可召开朝会

#### 4.2 朝会面板
- **标题**：朝廷会议 ⭐
- **副标题**：诸位爱卿，有事启奏，无事退朝。
- **事件计数**：显示当前待处理事件数量
- **事件显示**：一次显示一个事件
  - 事件编号（第X/总数件）
  - 事件优先级标识
  - 事件标题
  - 事件详细描述
  - 决策选项按钮

#### 4.3 交互流程
1. 点击"朝会"按钮
2. 系统生成随机事件（如果还没有待处理事件）
3. 显示第一个事件
4. 玩家选择决策选项
5. 显示决策结果
6. 自动显示下一个事件（如果有）
7. 处理完所有事件后自动关闭面板

### 5. 技术实现

#### 5.1 核心文件
- `js/data/courtMeeting.js` - 朝会系统核心逻辑
- `js/data/gameState.js` - 集成到游戏状态管理
- `js/ui/uiManager.js` - UI显示和交互
- `css/style.css` - 朝会界面样式

- constructor(gameState) // 初始化

- triggerCourtMeeting() // 触发朝会
- generateRandomEvents() // 生成随机事件

- getPendingEvents() // 获取待处理事件

```javascript

```

**UIManager 显示方法**
```javascript
- triggerCourtMeeting() // 触发朝会

```

#### 5.3 事件数据结构
```javascript
{
    id: string,              // 唯一标识
    type: string,            // 事件类型
    title: string,           // 事件标题
    description: string,     // 事件描述
    options: [               // 决策选项
        {
            text: string,    // 按钮文字
            callback: function // 回调函数
        }
    ],
    priority: number,        // 优先级 0-3
    timestamp: number,       // 时间戳
    resolved: boolean        // 是否已处理
}
```

## 使用指南

### 玩家操作流程

1. **召开朝会**
   - 点击底部控制栏的"朝会"按钮
   - 或者等待系统每30天自动触发

2. **查看事件**
   - 阅读事件标题和描述
   - 注意事件优先级标识
   - 评估决策选项的影响

3. **做出决策**
   - 点击合适的选项按钮
   - 查看决策结果消息
   - 资源和状态会立即更新

4. **处理后续事件**
   - 系统自动显示下一个事件
   - 继续做出决策
   - 所有事件处理完毕后面板自动关闭

### 策略建议

1. **资源管理**
   - 在接受需要消耗资源的建议前，先查看顶部资源栏
   - 保持足够的资源应对突发事件（特别是灾害）
   - 合理权衡短期消耗和长期收益

2. **优先级处理**
   - 优先处理标记为"紧急"的事件（如灾害）
   - 重要事件（如政策）需要仔细考虑长期影响
   - 普通事件可以根据当前资源情况灵活选择

3. **政策选择**
   - 轻徭薄赋适合资源充足、追求稳定发展的玩家
   - 屯田政策适合粮食短缺的局面
   - 军备强化适合准备扩张的时期

4. **人事管理**
   - 优先任命政治属性高的武将为太守
   - 统率高的武将留作军队统帅
   - 合理分配武将提高城池发展效率

## 未来扩展

### 计划功能

1. **更多事件类型**
   - 科技发现事件
   - 人才招揽事件
   - 商贸机会事件
   - 民生问题事件

2. **武将性格影响**
   - 不同性格的武将提出不同类型的建议
   - 武将忠诚度影响建议质量
   - 武将属性影响建议效果

3. **势力关系影响**
   - 其他势力的使者来访
   - 结盟/宣战请求
   - 贸易协定提议
   - 领土交换谈判

4. **季节性事件**
   - 春季：农业相关事件增加
   - 夏季：灾害概率提高
   - 秋季：收获相关事件
   - 冬季：军事活动受限

5. **连锁事件**
   - 某些决策会触发后续事件
   - 长期政策影响累积
   - 事件之间的因果关系

6. **历史事件**
   - 基于三国历史的特殊事件
   - 著名战役的重现
   - 历史人物的登场
