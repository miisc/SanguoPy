# 军队道路移动系统

## 功能说明

军队现在只能沿着道路移动，并且只能驻扎在城市中。

## 核心特性

### 1. 限制移动路径
- ✅ **只能沿道路移动**：军队必须通过已建造的道路网络移动
- ✅ **只能驻扎在城市**：军队必须移动到城市，不能移动到地图上的任意位置
- ✅ **路径自动计算**：系统自动查找两个城市之间的最短道路路径

### 2. 路径查找算法
使用 **BFS（广度优先搜索）** 算法查找城市之间的最短路径：
- 构建道路网络的邻接表
- 搜索从起始城市到目标城市的路径
- 如果没有道路连接，拒绝移动请求

### 3. 用户交互
1. **选择军队**：点击地图上的军队图标
2. **选择目标城市**：点击目标城市
3. **自动移动**：系统计算路径并开始移动
4. **路径提示**：弹窗显示军队将经过的城市路径

## 使用示例

### 1. 招募军队
```javascript
// 在成都招募军队
gameState.recruitArmy('chengdu', 'liubei', 1000);
```

### 2. 移动军队
```javascript
// 移动军队从成都到襄阳（通过汉中）
gameState.moveArmyToCity('army1', 'xiangyang');
// 系统自动查找路径: 成都 → 汉中 → 襄阳
```

### 3. 无法到达
```javascript
// 尝试移动到没有道路连接的城市
gameState.moveArmyToCity('army1', 'isolated_city');
// 返回: { success: false, message: "无法通过道路到达该城市，请建造道路连接" }
```

## 战略影响

### 道路的重要性
- 🏗️ **建造道路**：控制道路网络决定了军队的机动性
- ⚔️ **切断补给线**：占领关键城市可以切断敌军的移动路径
- 🛡️ **防守要塞**：控制道路枢纽城市（如襄阳、江陵）具有战略价值

### 军事策略
- **快速反应**：必须提前在关键位置驻扎军队
- **道路控制**：占领连接道路的城市非常重要
- **包围作战**：可以通过控制道路网络包围敌方城市

## 后续优化

### 可添加的功能
1. **道路等级影响速度**：
   - 官道（等级3）：移动速度 × 1.5
   - 驿道（等级2）：移动速度 × 1.2
   - 小路（等级1）：移动速度 × 1.0

2. **道路状况影响**：
   - 道路状况好（90-100）：正常速度
   - 道路状况中（50-89）：速度 × 0.8
   - 道路状况差（0-49）：速度 × 0.5

3. **建造新道路**：
   - 玩家可以花费资源建造新道路
   - 建造时间取决于距离和地形

4. **破坏道路**：
   - 军队可以破坏敌方控制的道路
   - 降低道路状况或暂时阻断

- ✅ 目标城市不存在
