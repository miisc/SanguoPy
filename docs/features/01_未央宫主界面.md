# 未央宫主界面

## 功能描述
实现未央宫全景地图的基础UI框架，作为游戏的主界面，为后续功能提供界面基础。

## 功能要点
- 未央宫全景地图作为游戏主界面
- 基础界面布局和导航结构
- 界面响应式设计基础
- 基础UI组件和样式系统

## 界面布局
- **主视图区域**：占据屏幕中央70%区域，展示未央宫全景2D平面图
- **信息面板**：位于屏幕右侧，显示当前选中宫殿/人员的基本信息
- **功能按钮区**：位于屏幕底部，提供系统设置、存档等常用功能
- **状态栏**：位于屏幕顶部，显示当前时间、资源、季节等游戏状态

## 未央宫简化结构
根据MVP需求，未央宫主要分为以下核心宫殿：

### 前朝区域
- **宣室殿**：处理紧急朝会，应对突发事件
- **承明殿**：处理每月初一的大朝会

### 后宫区域
- **椒房殿**：后宫管理
- **长乐宫**：皇室事务

## 技术要点
- 使用PyQt的QGraphicsScene和QGraphicsItem实现2D场景
- 采用分层渲染，背景层、建筑层、UI层分离
- 实现响应式布局，适配不同分辨率
- 优化渲染性能，确保流畅的交互体验
- 实现场景状态管理，保存和恢复界面状态

## 交互设计
- 主界面基础交互
- 界面元素基础响应
- 简单的导航机制
- 鼠标悬停显示宫殿名称和功能

## 视觉设计
- **整体风格**：采用汉代建筑风格，色彩以朱红、金黄为主
- **平面表现**：使用2D平面设计，注重信息展示的清晰度
- **图标设计**：宫殿使用简洁的图标表示，不同功能宫殿有不同图标
- **色彩系统**：前朝区域使用暖色调，后宫区域使用柔和色调

## 开发步骤
1. 创建基础场景框架和布局
2. 设计和实现未央宫2D平面图
3. 实现宫殿的基础交互逻辑
4. 添加信息面板和状态显示
5. 实现基础的视觉效果
6. 优化性能和响应速度

## 开发注意事项
- 为后续宫殿交互预留接口
- 考虑界面扩展性
- 确保基础性能优化
- 简化设计，专注核心功能
