# 实时制系统更新说明

## 更新日期：2026-02-14

### 主要改动

游戏已从**回合制**改为**实时制**，提供更流畅的游戏体验。

### 新功能

#### 1. 实时时间流逝 ⏱️
- **1秒现实时间 = 1天游戏时间**（正常速度）
- 时间自动流逝，无需手动推进
- 每30天自动切换季节
- 季节循环完成后自动增加年份

#### 2. 速度控制 🎮
- **1x** - 正常速度（默认）
- **2x** - 2倍速度
- **4x** - 4倍速度  
- **⏸ 暂停** - 暂停游戏时间

#### 3. 实时资源更新 💰
- 资源每天自动更新
- 城池产出实时计算
- 武将俸禄实时扣除

### 操作方式

**原有操作**（保持不变）：
- 鼠标拖拽平移地图
- 滚轮缩放地图
- 点击城池查看信息
- 查看城池和武将列表

**新增操作**：
- 点击"⏸ 暂停"按钮暂停/继续游戏
- 点击速度按钮（1x/2x/4x）调整游戏速度
- 当前激活的速度按钮会显示高亮

### 界面变化

**移除**：
- ❌ "下一回合"按钮

**新增**：
- ✅ "⏸ 暂停"按钮（可切换暂停/继续）
- ✅ 速度控制区域（1x/2x/4x按钮）
- ✅ 速度按钮高亮显示当前状态

### 技术细节

#### 修改的文件：
1. `js/data/gameState.js` - 核心游戏状态管理
2. `js/main.js` - 游戏主循环
3. `js/ui/uiManager.js` - UI交互控制
4. `index.html` - 按钮布局
5. `css/style.css` - 按钮样式

#### 核心算法：
```javascript
// 时间流逝计算
游戏天数 = (实际经过毫秒数 / 1000) * 游戏速度倍数

// 每天资源更新
每天产出 = 每回合产出 / 30天
```

### 兼容性说明

- 所有数据结构向后兼容
