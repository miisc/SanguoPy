# 未央宫主界面设计

## 功能描述
未央宫主界面是游戏的核心界面，以东汉未央宫全景地图为主要表现形式，作为整个游戏的交互中心。玩家通过点击不同宫殿处理各类政务，体现前朝后宫严格分离的历史真实机制。

## 界面布局
- **主视图区域**：占据屏幕中央70%区域，展示未央宫全景2D平面图
- **信息面板**：位于屏幕右侧，显示当前选中宫殿/人员的基本信息
- **功能按钮区**：位于屏幕底部，提供系统设置、存档等常用功能
- **状态栏**：位于屏幕顶部，显示当前时间、资源、季节等游戏状态

## 未央宫结构设计
根据历史资料，未央宫主要分为前朝和后宫两部分：

### 前朝区域
- **宣室殿**：处理政务、朝会的主要场所
- **承明殿**：接见大臣、处理外交事务
- **麒麟阁**：表彰功臣、展示功绩
- **金銮殿**：举行重大典礼
- **尚书台**：处理文书、诏令
- **太官署**：管理宫廷饮食

### 后宫区域
- **椒房殿**：皇后居所，处理后宫事务
- **长秋宫**：太后居所
- **增成宫**：妃嫔居所
- **永巷**：宫女居所
- **掖庭**：宫中服务人员

## 交互设计
- **宫殿选择**：鼠标悬停显示宫殿名称和功能，点击进入宫殿内部界面
- **区域划分**：前朝后宫有明确的视觉区分，体现历史真实机制
- **状态指示**：不同宫殿根据当前状态显示不同颜色或图标
- **快速导航**：提供宫殿快速导航菜单，方便直接跳转

## 视觉设计
- **整体风格**：采用汉代建筑风格，色彩以朱红、金黄为主
- **平面表现**：使用2D平面设计，注重信息展示的清晰度
- **图标设计**：宫殿使用简洁的图标表示，不同功能宫殿有不同图标
- **色彩系统**：前朝区域使用暖色调，后宫区域使用柔和色调

## 信息展示
- **宫殿状态**：显示当前宫殿内的人员数量、待处理事务等
- **人员信息**：显示重要人物的基本信息和状态
- **事件提示**：显示当前需要处理的事件和紧急事务
- **时间流动**：通过视觉效果表现时间的流逝和季节变化

## 技术实现要点
- 使用PyQt的QGraphicsScene和QGraphicsItem实现2D场景
- 采用分层渲染，背景层、建筑层、UI层分离
- 实现响应式布局，适配不同分辨率
- 优化渲染性能，确保流畅的交互体验
- 实现场景状态管理，保存和恢复界面状态

## 开发步骤
1. 创建基础场景框架和布局
2. 设计和实现未央宫2D平面图
3. 实现宫殿的交互逻辑
4. 添加信息面板和状态显示
5. 实现视觉效果和动画
6. 优化性能和响应速度
7. 测试和调整交互体验

## 测试要点
- 宫殿识别的准确性和直观性
- 交互响应的速度和准确性
- 不同分辨率下的显示效果
- 长时间使用的性能表现
- 历史元素的准确性和表现力
