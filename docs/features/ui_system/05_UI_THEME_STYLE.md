# UI主题与风格设计

## 功能描述
UI主题与风格系统负责统一整个游戏的视觉风格和主题，确保UI设计符合东汉末年的历史背景和文化特色。系统提供多种主题选择，并支持一定程度的自定义，满足不同玩家的审美需求。

## 设计原则
- **历史真实性**：UI设计元素符合东汉末年的历史背景
- **文化特色**：融入汉代文化和艺术特色
- **视觉统一**：保持整体视觉风格的一致性
- **可读性强**：确保文字和图标在各种背景下清晰可读
- **性能优化**：主题切换不影响游戏性能

## 基础主题设计

### 汉代宫廷主题
- **设计理念**：基于汉代宫廷建筑和艺术风格
- **主色调**：朱红、金黄、墨黑、象牙白
- **装饰元素**：汉代云纹、龙纹、凤纹
- **字体风格**：篆书风格的装饰字体，楷书风格的内容字体
- **材质表现**：丝绸、玉石、青铜、木材等传统材质
- **适用场景**：默认主题，最符合历史背景

### 简约现代主题
- **设计理念**：简化传统元素，突出功能性
- **主色调**：深蓝、浅灰、白色、强调色
- **装饰元素**：简化的几何图形，线条装饰
- **字体风格**：现代无衬线字体
- **材质表现**：扁平化设计，弱化材质感
- **适用场景**：偏好现代风格的玩家

### 暗黑主题
- **设计理念**：减少视觉疲劳，适合长时间游戏
- **主色调**：深灰、黑色、暗红、淡金
- **装饰元素**：简化的暗色装饰元素
- **字体风格**：高对比度的字体
- **材质表现**：哑光材质，减少反光
- **适用场景**：夜间游戏或对光敏感的玩家

## 图标系统

### 图标风格
- **线条图标**：简洁的线条风格，用于功能按钮

- **传统图标**：融入传统元素的图标，用于特色功能

- **大图标**：48×48px（用于重要功能）

- **小图标**：24×24px（用于辅助功能）
- **特小图标**：16×16px（用于状态指示）

## 界面元素设计

### 按钮设计
- **主要按钮**：圆角矩形，宫廷红背景，金色边框
- **次要按钮**：圆角矩形，象牙白背景，墨黑边框
- **图标按钮**：圆形或方形，透明背景，悬停显示背景色
- **状态按钮**：根据状态显示不同颜色和样式

### 面板设计
- **主面板**：圆角矩形，象牙白背景，淡金色边框
- **信息面板**：直角矩形，浅灰背景，细边框
- **对话面板**：特殊形状，融入传统装饰元素
- **状态面板**：半透明背景，模糊效果

### 输入控件
- **文本框**：圆角矩形，象牙白背景，墨黑边框
- **下拉框**：圆角矩形，象牙白背景，墨黑边框，右侧下拉箭头
- **复选框**：方形，宫廷红背景，金色勾选标记
- **单选框**：圆形，宫廷红背景，金色选中标记

## 动画与过渡效果

### 界面切换
- **淡入淡出**：0.3秒的透明度变化
- **滑动效果**：0.2秒的平滑滑动
- **缩放效果**：0.2秒的轻微缩放
- **弹性效果**：重要元素的弹性动画

### 交互反馈
- **按钮点击**：0.1秒的按下效果
- **悬停效果**：0.2秒的颜色变化
- **选中效果**：0.1秒的高亮显示
- **错误提示**：0.5秒的震动效果

## 主题切换系统

### 主题管理
- **主题选择**：提供主题选择界面
- **实时切换**：支持实时预览和切换主题
- **自定义选项**：允许调整主题中的颜色和字体
- **主题保存**：保存用户的自定义主题设置

### 主题元素
- **颜色配置**：可配置的颜色方案
- **字体配置**：可配置的字体方案
- **图标配置**：可配置的图标风格
- **动画配置**：可配置的动画效果

## 技术实现要点
- 使用QSS（Qt样式表）实现主题系统
- 实现主题资源的动态加载和切换
- 采用资源管理器统一管理主题资源
- 优化主题切换性能，避免卡顿
- 实现主题配置的保存和加载

## 开发步骤
1. 设计基础色彩和字体系统
2. 创建汉代宫廷主题
3. 实现界面元素的设计规范
4. 创建主题切换系统
5. 添加其他主题选项
6. 实现自定义主题功能
7. 添加动画和过渡效果
8. 优化性能和用户体验

- 主题元素的视觉一致性和美观性
- 主题切换的流畅性和稳定性
- 不同分辨率下的显示效果
- 长时间使用的视觉舒适度
- 历史元素的准确性和表现力
