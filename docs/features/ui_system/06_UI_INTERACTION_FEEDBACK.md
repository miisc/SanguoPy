# 交互反馈系统

本文档描述三国策略游戏UI系统的交互反馈设计，为用户提供清晰、及时的操作反馈，增强用户体验。

## 设计原则

### 即时性
- **即时反馈**：操作后立即提供反馈
- **状态可见**：清晰显示当前状态
- **进度指示**：长时间操作显示进度
- **结果通知**：操作完成后通知结果

### 明确性
- **信息明确**：反馈信息清晰明确
- **状态区分**：不同状态有明显区分
- **错误提示**：错误情况有明确提示
- **成功确认**：成功操作有确认反馈

### 一致性
- **风格一致**：反馈风格保持一致
- **行为一致**：相似操作反馈一致
- **位置一致**：反馈位置保持一致
- **时机一致**：反馈时机保持一致
