# 信息展示与反馈系统

## 功能描述
信息展示与反馈系统是UI系统的核心支撑模块，负责向玩家清晰、直观地展示游戏中的各类信息，并提供及时的操作反馈。系统采用多层次的信息展示方式，确保玩家能够快速获取所需信息并理解游戏状态。

## 设计原则
- **信息清晰**：使用简洁明了的方式展示信息
- **层次分明**：重要信息突出显示，次要信息适当弱化
- **反馈及时**：所有操作都有即时的视觉和文字反馈
- **一致性**：保持信息展示风格的一致性

## 信息展示层次

### 核心信息层
- **游戏状态**：当前时间、季节、年份等基本信息
- **资源状态**：金钱、粮食、木材等核心资源
- **紧急事件**：需要立即处理的重要事件
- **军事警报**：敌军入侵、城池被攻击等紧急军事情况

### 主要信息层
- **城池状态**：人口、守军、民心、发展度等
- **武将状态**：忠诚度、健康状态、当前任务等
- **军队状态**：位置、数量、士气、补给等
- **外交关系**：与其他势力的关系状态

### 次要信息层
- **详细数据**：各项属性的具体数值
- **历史记录**：过去发生的事件和决策
- **统计信息**：各类数据的统计和分析
- **提示信息**：操作提示和帮助信息

## 信息展示组件

### 状态栏
- **位置**：屏幕顶部
- **内容**：游戏时间、季节、核心资源、紧急提示
- **特点**：始终可见，使用图标和简洁文字
- **交互**：点击可展开详细信息

### 信息面板
- **位置**：屏幕右侧
- **内容**：当前选中对象（城池、人物、军队等）的详细信息
- **特点**：根据选中对象动态变化
- **交互**：支持滚动查看和标签切换

### 提示框
- **触发方式**：鼠标悬停在元素上
- **内容**：元素的基本信息和简要说明
- **特点**：简洁明了，快速显示和隐藏
- **样式**：统一的样式和动画效果

### 通知系统
- **位置**：屏幕右上角
- **内容**：游戏事件、操作结果、系统提示
- **类型**：普通通知、重要通知、紧急通知
- **特点**：自动消失，可手动关闭，有历史记录

## 反馈系统

### 视觉反馈
- **按钮状态**：正常、悬停、点击、禁用等状态
- **选中效果**：选中元素的高亮和边框效果
- **操作结果**：成功、失败、警告等不同状态的视觉提示
- **进度指示**：加载进度、操作进度等进度条显示

### 动画反馈
- **界面切换**：平滑的界面切换动画
- **元素变化**：数值变化、状态变化的动画效果
- **操作确认**：重要操作的确认动画
- **事件提醒**：重要事件的提醒动画

### 声音反馈
- **操作音效**：点击、选择等操作的音效
- **事件音效**：重要事件的声音提醒
- **环境音效**：增强沉浸感的环境音效
- **静音选项**：提供音量控制和静音选项

### 文字反馈
- **操作提示**：操作结果的文字说明
- **错误信息**：错误操作的详细说明和建议
- **帮助信息**：复杂操作的帮助和指导
- **历史记录**：重要操作和事件的文字记录

## 信息定制系统

### 显示选项
- **信息密度**：提供简洁、标准、详细三种信息密度
- **显示内容**：允许玩家选择显示哪些信息类别
- **布局调整**：允许玩家调整信息面板的位置和大小
- **字体设置**：提供字体大小和样式选择

### 过滤系统
- **重要性过滤**：根据重要性过滤显示的信息
- **时间过滤**：根据时间范围过滤历史信息
- **类型过滤**：根据类型过滤不同类别的信息
- **关键词过滤**：根据关键词搜索和过滤信息

## 特殊信息展示

### 军事信息
- **军队移动**：在地图上实时显示军队移动路径
- **战斗结果**：使用图标和文字展示战斗结果
- **战略态势**：使用颜色和图标展示战略态势
- **补给状态**：清晰显示军队补给线和状态

### 经济信息
- **资源流动**：使用箭头和数字显示资源流动
- **贸易路线**：显示贸易路线和收益
- **市场行情**：显示市场价格和波动
- **建设进度**：显示建设项目的进度

### 外交信息
- **关系图**：使用网络图显示势力间关系
- **外交事件**：突出显示重要外交事件
- **使臣状态**：显示使臣位置和任务状态
- **条约内容**：详细显示条约内容和效果

## 技术实现要点
- 使用PyQt的信号槽机制实现信息更新
- 采用观察者模式管理信息变化和更新
- 实现信息缓存和延迟加载机制
- 优化信息渲染性能，确保流畅显示
- 实现信息历史记录和回放功能

## 开发步骤
1. 创建基础信息展示框架
2. 实现状态栏和基本信息显示
3. 创建信息面板和详细信息展示
4. 实现提示框和通知系统
5. 添加反馈系统和动画效果
6. 实现信息定制和过滤功能
7. 优化性能和响应速度
8. 测试和调整用户体验

## 测试要点
- 信息展示的准确性和完整性
- 反馈系统的及时性和有效性
- 不同信息密度的显示效果
- 长时间使用的性能表现
- 用户定制的灵活性和易用性
