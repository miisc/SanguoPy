# 朝会系统 - 快速入门

## 如何使用朝会系统

### 方法一：手动触发

1. 启动游戏后，查看底部控制栏
2. 找到**金色的"朝会"按钮**（位于"军事"和"内政"之间）
3. 点击该按钮
4. 朝会面板将弹出，显示当前的待处理事件

### 方法二：自动触发

- 系统会每**30天**（约一个游戏月）自动生成新的朝会事件
- 当有新事件时，朝会面板会自动弹出
- 无需玩家手动操作

## 处理朝会事件

### 1. 查看事件信息

朝会面板会显示：
- **事件编号**：当前是第几个事件（如"第1/3件"）
- **优先级标识**：
  - ★★★ 紧急（红色）- 需要立即处理
  - ★★ 重要（橙色）- 重要决策
  - ★ 一般（蓝色）- 常规事务
  - 普通（灰色）- 日常事项
- **事件标题**：事件的名称
- **事件描述**：详细说明当前情况

### 2. 做出决策

- 阅读每个选项按钮的说明
- 注意选项中的**资源消耗**和**效果说明**
  - 例如："准奏（金钱-500，民心+10）"
- 点击你选择的选项按钮
- 系统会显示决策结果

### 3. 处理后续事件

- 处理完一个事件后，系统会**自动显示下一个事件**
- 继续做出决策，直到所有事件处理完毕
- 所有事件处理完后，面板会自动关闭

## 事件类型说明

### 📊 经济报告
- **频率**：每次朝会必出现
- **作用**：查看当前国库状况和资源产量
- **决策**：只需点击"知道了"即可

### 💬 大臣建言
- **内容**：大臣提出各种建议
- **类型**：
  - 减税惠民 - 提升民心但消耗金钱
  - 加强军备 - 增加各城驻军
  - 发展农业 - 增加粮食储备
- **建议**：根据当前资源状况和战略需求选择

### 📜 政策建议
- **影响**：长期改变资源产量
- **类型**：
  - 轻徭薄赋 - 减少金钱收入，提升民心
  - 屯田政策 - 增加粮食产量
- **注意**：政策一旦实施，效果是持续性的

### 👥 人事推荐
- **触发条件**：有城池缺少太守
- **作用**：为城池任命太守
- **建议**：选择**政治属性高**的武将

### ⚠️ 灾害报告
- **频率**：20%概率出现
- **类型**：洪涝、旱灾、蝗灾
- **建议**：
  - 如果金钱充足，选择"拨款赈灾"减轻损失
  - 如果资源紧张，只能"听天由命"
- **注意**：这是高优先级事件，会造成实际损失

### 🎁 宝物献上
- **频率**：10%概率出现
- **作用**：免费获得资源
- **建议**：直接点击"收下宝物"即可

## 实用技巧

### 资源管理建议

1. **保持储备**
   - 始终保持至少1000金钱用于应对灾害
   - 粮食不足时优先选择农业相关建议

2. **优先级处理**
   - 先处理标记为"紧急"的灾害事件
   - 政策建议需要仔细考虑长期影响

3. **武将分配**
   - 政治高的武将任命为太守
   - 统率高的武将留作军队统帅

### 常见问题

**Q：为什么点击朝会按钮没有事件？**
A：如果距离上次朝会不到30天且没有未处理事件，系统会提示"当前无事件需要处理"。

**Q：可以跳过某些事件吗？**
A：不可以跳过，但每个事件都有"不采纳"、"暂缓"等选项，可以选择不执行该建议。

**Q：灾害是否可以避免？**
A：灾害是随机发生的，无法避免，但可以通过拨款赈灾来减轻损失。

**Q：处理错误的决策可以撤回吗？**
A：不可以撤回，请在做决策前仔细考虑。建议在重要决策前先保存游戏。

**Q：朝会事件是否会影响AI势力？**
A：当前版本朝会系统只影响玩家势力。
