# 武将系统功能文档

## 系统概述

武将系统是三国策略游戏中的核心人物管理系统，负责管理游戏中的所有武将，包括他们的属性、技能、关系和成长。武将是玩家与游戏世界互动的主要媒介，也是军事、内政、外交等活动的重要参与者。
