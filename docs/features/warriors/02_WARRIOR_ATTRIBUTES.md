# 武将属性系统

本文档描述三国策略游戏武将系统的属性设计与实现。

## 属性体系

### 核心四维属性
武将系统采用四维核心属性体系：
- **武力**：影响武将的战斗能力和军事指挥效果
- **智力**：影响武将的策略制定和内政管理效果
- **统率**：影响武将的军队指挥和士气维持效果
- **魅力**：影响武将的外交效果和人才招募能力

### 辅助属性
除了核心四维属性外，还有以下辅助属性：
- **忠诚度**：武将对当前势力的忠诚程度
- **士气**：武将当前的精神状态和战斗意志
- **健康**：武将的身体状况和耐久能力
- **经验**：武将的经验积累和成长潜力

## 属性计算

### 基础属性值
武将的基础属性值由以下因素决定：
- **历史评价**：基于历史记载的武将评价
- **年龄因素**：不同年龄阶段对属性的影响
- **出身背景**：武将出身对初始属性的影响
- **天赋因素**：武将的天赋对属性的影响

### 动态属性修正
武将属性在游戏中会受到多种因素影响：
- **装备加成**：装备对武将属性的加成效果
- **官职加成**：官职对武将属性的加成效果
- **城池加成**：所在城池对武将属性的影响
- **关系加成**：与其他武将关系对属性的影响
- **事件影响**：特定事件对武将属性的临时影响

### 属性上限与下限
- **基础上限**：基于等级的属性上限
- **绝对上限**：属性的最大可能值
- **基础下限**：基于等级的属性下限
- **绝对下限**：属性的最小可能值

## 属性成长

### 经验获取
武将通过以下活动获取经验：
- **军事行动**：参与战斗和军事指挥
- **内政管理**：管理城池和处理内政
- **外交活动**：进行外交谈判和使节任务
- **特殊事件**：参与特殊历史事件
- **日常活动**：日常的政务和军事活动

### 等级提升
武将等级提升时的属性变化：
- **基础属性增长**：根据武将特点增长不同属性
- **成长点分配**：玩家可自由分配的成长点数
- **天赋觉醒**：特定等级可能觉醒特殊天赋
- **技能解锁**：等级提升可能解锁新技能

### 属性衰减
某些情况下武将属性会衰减：
- **年龄增长**：高龄武将部分属性会自然衰减
- **长期闲置**：长期不参与活动会导致属性下降
- **伤病影响**：伤病可能导致永久性属性损失
- **忠诚下降**：忠诚度低会影响属性发挥

## 属性应用

### 军事应用
- **战斗计算**：武力影响战斗伤害和防御
- **指挥效果**：统率影响军队战斗力和士气
- **战术执行**：智力影响战术选择和执行效果
- **特殊能力**：高属性可能触发特殊战斗能力

### 内政应用
- **城池管理**：智力影响城池发展效率
- **资源产出**：统率影响资源管理和产出
- **民心管理**：魅力影响民心稳定和提升
- **建设效率**：综合属性影响建设速度和质量

### 外交应用
- **谈判效果**：魅力影响外交谈判成功率
- **使节任务**：智力影响使节任务执行效果
- **联盟建立**：综合属性影响联盟建立难度
- **间谍活动**：特定属性组合影响间谍活动效果

## 属性平衡

### 平衡原则
- **历史真实性**：属性设置符合历史人物特点
- **游戏平衡性**：不同属性武将有各自价值
- **成长可能性**：所有属性都有成长空间
- **特色鲜明**：不同武将有明显属性特色

### 平衡机制
- **属性互补**：不同属性武将可以互补
- **场景适应**：不同场景需要不同属性武将
- **团队协作**：武将组合发挥更大效果
- **策略多样性**：多种策略路线可选

## 属性展示

### 界面展示
- **属性面板**：显示武将的详细属性信息
- **对比界面**：支持多个武将属性对比
- **成长预览**：显示武将可能的成长方向
- **属性分析**：分析武将的优缺点

### 视觉表现
- **属性条**：用进度条直观显示属性值
- **雷达图**：用雷达图显示属性分布
- **颜色编码**：用颜色区分属性高低
- **趋势指示**：显示属性变化趋势

## 特殊属性

### 隐藏属性
部分武将可能有隐藏属性：
- **特殊天赋**：特定条件下才显示的天赋
- **潜在能力**：需要特定条件才能激发的能力
- **成长潜力**：影响未来成长幅度的潜在属性
- **特殊关系**：与特定人物的特殊关系加成

### 临时属性
某些情况下武将可能有临时属性：
- **状态加成**：特定状态下的属性加成
- **环境加成**：特定环境下的属性加成
- **事件加成**：特定事件触发的临时加成
- **组合加成**：特定武将组合的加成效果
