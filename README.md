# 三国志策略游戏

一款基于PyQt的单机策略游戏，背景设定在三国时期。

## 项目简介

本项目是一个使用PyQt框架开发的三国题材策略游戏，玩家将扮演三国时期的君主，通过军事、外交、经济等手段统一三国。

## 核心特点

- 实时制游戏玩法
- 三国历史背景
- 完整的城池、武将、军队系统
- 朝会与政务系统
- 经济与外交系统
- 事件与历史系统

## 如何运行

```bash
# 安装依赖
pip install PyQt5

# 运行游戏
python main.py
```

## 技术架构

- **框架**: PyQt5
- **架构模式**: MVC (Model-View-Controller)
- **编程语言**: Python 3.8+
- **数据存储**: JSON文件 + SQLite数据库
- **图形渲染**: QGraphicsScene/QGraphicsView
