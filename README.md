# 三国志策略游戏

一个基于PyQt5的三国志题材策略游戏，以东汉未央宫为核心界面，通过宫殿交互实现政务处理。

## 快速开始

### 环境要求
- Python 3.8+
- PyQt5

### 安装运行
```bash
# 克隆项目
git clone [项目地址]
cd SanGuoHtmlDemo

# 安装依赖
pip install -r requirements.txt

# 运行游戏
python src/main.py
```

## 项目结构

```
SanGuoHtmlDemo/
├── src/                 # 源代码
│   ├── game/           # 游戏核心逻辑
│   ├── map_system/     # 地图系统
│   └── ui/             # 用户界面
├── data/               # 游戏数据
├── docs/               # 详细文档
└── resources/          # 资源文件
```

## 核心功能

- **宫殿系统**：以未央宫为核心的政务处理界面
- **地图系统**：2D网格化三国地图，支持城池、关隘和地形展示
- **武将系统**：武将属性、技能、关系和招募系统
- **朝会系统**：处理国家政务和决策
