# 三国志策略游戏 - 基础朝会框架

## 概述

本项目实现了三国志策略游戏的基础朝会框架与UI，包括：

1. **基础游戏框架**：MVC架构的游戏基础框架
2. **朝会系统**：完整的朝会流程和决策系统
3. **用户界面**：基于PyQt5的图形界面

## 功能特性

### 朝会系统

- **定期朝会机制**：每季度可召开一次朝会
- **议题生成**：根据游戏状态自动生成朝会议题
- **朝臣参与**：随机选择武将参与朝会并发表意见
- **决策系统**：君主从多个方案中选择执行
- **结果影响**：不同选择对国家产生不同影响

### 用户界面

- **主窗口**：显示游戏基本信息和控制按钮
- **地图视图**：显示城池和势力分布
- **朝会对话框**：完整的朝会流程界面
- **资源显示**：实时显示金钱、粮食、人口和士兵数量

## 安装与运行

### 环境要求

- Python 3.8+
- PyQt5

### 安装步骤

1. 创建虚拟环境（推荐）：
```bash
python -m venv venv
```

2. 激活虚拟环境：
- Windows: `venv\Scripts\activate`
- macOS/Linux: `source venv/bin/activate`

3. 安装依赖：
```bash
pip install -r requirements.txt
```

4. 运行游戏：
```bash
python main.py
```

## 使用说明

### 基本操作

1. **开始新游戏**：通过菜单栏"游戏" -> "新游戏"
2. **推进时间**：点击"下一回合"按钮
3. **召开朝会**：点击"召开朝会"按钮
4. **做出决策**：在朝会对话框中选择一个选项并确认

### 朝会流程

1. 点击"召开朝会"按钮打开朝会对话框
2. 查看议题信息和背景
3. 阅读朝臣意见和建议
4. 选择一个决策选项
5. 确认决策，查看结果
