## 如何运行

### 方法1：使用本地服务器（推荐）

由于使用了ES6模块，需要通过HTTP服务器运行：

```bash
# 使用Python（如果已安装）
python -m http.server 8000

# 或使用Node.js的http-server（需要先安装：npm install -g http-server）
http-server -p 8000

# 或使用PHP（如果已安装）
php -S localhost:8000
```

然后在浏览器中访问：`http://localhost:8000`

### 方法2：使用VS Code Live Server

1. 安装VS Code的"Live Server"扩展
2. 右键点击 `index.html`
3. 选择"Open with Live Server"

## 功能说明

### 当前可用功能

1. **地图系统**
   - 显示三国地图（简化版2D网格）
   - 城池标记和颜色区分（按势力）
   - 鼠标拖拽平移地图
   - 鼠标滚轮/按钮缩放地图
   - 点击城池查看详细信息

2. **势力系统**
   - 三个初始势力：蜀、魏、吴
   - 玩家扮演蜀国
   - 势力资源管理（金钱、粮食、木材）

3. **城池系统**
   - 基础城池属性（人口、守军、城墙等）
   - 城池产出计算
   - 城池列表查看

4. **武将系统**
   - 初始武将：刘备、关羽、张飞、曹操、孙权
   - 武将属性（武力、智力、统率、魅力等）
   - 武将列表查看

5. **实时系统**
   - 时间实时流逝（1秒现实 = 1天游戏时间）
   - 时间速度控制（1x/2x/4x/暂停）
   - 实时资源更新
   - 季节自动变化
   - 年份自动推进

6. **UI系统**
   - 顶部信息栏（日期、势力、资源）
   - 底部控制按钮
   - 信息面板（可拖拽关闭）
   - 游戏保存/加载

## 操作说明

- **地图拖动**：鼠标左键拖拽
- **地图缩放**：鼠标滚轮或右上角按钮
- **查看城池**：点击地图上的城池圆点
- **查看城池列表**：点击底部"城池"按钮
- **查看武将**：点击底部"武将"按钮
- **暂停/继续**：点击底部"⏸ 暂停"按钮切换暂停状态
- **调整速度**：点击1x/2x/4x按钮选择游戏速度
- **保存游戏**：点击"保存"按钮
- **加载游戏**：点击"加载"按钮
